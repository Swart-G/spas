| Файл | Назначение |
| --- | --- |
| `Server.py` | MCP-инструмент, вызов внешней проверки, выдача результата. |

## Подключение Safety Checker

объект с методом:

```python
async def check(command: str, context: ExecutionContext) -> SafetyDecision:
    ...
```

Он передаётся в `create_server(checker=checker)`. Можно вернуть
`SafetyDecision` или словарь вида
`{"decision": "ALLOW", "reason": "Причина решения"}`.
Это локальный контракт интеграции с внешним Safety Checker.
Транспорт к удалённому checker здесь не реализован.


Executor передаёт исходную команду и контекст без изменения. Только `ALLOW`
запускает команду. `DENY` и `REQUIRE_APPROVAL` возвращают отказ или запрос
подтверждения без запуска. Сам процесс согласования здесь не реализован.
При отсутствии checker, ошибке, неверном ответе или превышении 5 секунд
ожидания команда также не запускается. Совмещать подключённый checker и
режим `without-safety` нельзя.
