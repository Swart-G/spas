# DIAGNOSTIC
Агент, отвечающий за диагностику инцидента и определение вероятной причины сбоя.

`DiagnosticAgent` в `agent.py` — заглушка без внешних вызовов. На этапе
`diagnosis` возвращает `root_cause`, на этапе `verification` — boolean `resolved`
и описание проверки `details`. Оркестратор передаёт метрики, историю, а при
проверке также диагноз и выполненное действие. Заглушка всегда подтверждает
успешную проверку; это не является реальной проверкой инфраструктуры.

Реализация зависит только от общих контрактов и не наследует класс заглушки.
Для локального HTTP-стенда `DemoDiagnosticAgent` из `agents/demo.py` читает
фактическое состояние `DemoResource`; `HttpAgent` передаёт сообщения удалённому
обработчику. В Orchestrator подключается любой объект с ролью `DIAGNOSTIC` и
асинхронным `process(AgentMessage) -> AgentResult`.
