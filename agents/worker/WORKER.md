# WORKER
Агент устранения ошибки.
Pipeline работы:
    - Получает причину проблемы от Diagnostic.
    - Строит план устранения проблемы
    - Исполняет план с помощью executer_mcp.
    - Возвращает результат Оркестратору; тот вызывает Diagnostic для проверки.

`WorkerAgent` в `agent.py` — заглушка. Принимает этап `remediation` и контекст
с диагнозом, возвращает `action_taken`. Использует роль `RoleEnum.REMEDIATION`.
Внешние инструменты не вызываются. Отмена Worker блокирует автоматический повтор:
в реальной реализации действие могло уже выполниться. Положительный ответ Worker
сам по себе не означает `RESOLVED` — необходима отдельная проверка Diagnostic.

Реализация зависит только от общих контрактов. Для локального стенда
`DemoWorkerAgent` из `agents/demo.py` меняет состояние управляемого `DemoResource`;
при включённом отказе исправления состояние остаётся неисправным, что обнаруживает
отдельная проверка. HTTP-обмен использует `AgentMessage` / `AgentResult`.
При неопределённом завершении удалённого вызова повтор запрещён; закрытие
соединения не считается подтверждением отмены Worker на сервере.
